GitHub Dev Agentを使って、次のタスクを実装してください。

対象リポジトリ: OWNER/REPOSITORY
作業ID: 短い英小文字・数字・ハイフンの名前
依頼内容: 実装してほしい内容を書いてください
関連Issue: あれば番号、なければなし

system_statusを確認し、既存タスクの続きでなければstart_taskを使ってください。
README、AGENTS.md、言語・依存・テスト設定、関係するコードを読んでから変更してください。
範囲を勝手に広げず、受け入れ条件を満たす必要最小限の実装を行ってください。

バグ修正は再現テストを追加してください。必要な依存インストールとテストはworker内で実行してください。
start_commandのrequest_idは論理的なコマンドごとに分け、通信が不明だった同じ要求の再試行は同じIDを使ってください。
get_jobで終了状態・終了コード・出力を確認してください。ログが欠けていれば成功と断定しないでください。
テストが未実行・失敗・環境不足なら、その事実を分けて報告してください。

コマンド完了後にpublish_prでDraft PRを作成してください。本文に目的、変更点、検証、未解決事項を書いてください。
既存PRの続きなら同じtask_id、ブランチ、PRを再利用してください。
必要に応じてget_feedbackでCI結果を調べ、ci_jobs/ci_logで失敗理由を確認してください。

GitHub/OpenAIの認証情報を求めたり、MacのホームやDockerソケットを渡すよう要求したりしないでください。
git pushやデプロイ、mainへの直接反映、force push、マージ、workflow変更はしないでください。
最後にPRのURLと検証結果を示してください。
